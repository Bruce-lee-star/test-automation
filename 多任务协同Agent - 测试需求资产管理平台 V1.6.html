说明：MCP Server是独立stdio子进程；PlaywrightMcpClient是Java框架内置的完整JSON-RPC2.0客户端；资产文件仅本地生成，不会自动提交上传。
支持动态页面：通过循环交互+多次快照，捕获点击/下拉/输入后才渲染出来的弹窗、表格、级联下拉等动态元素。账号池支持多种登录模式：账号密码登录、SSO单点登录，可携带租户ID、域账号、二次校验参数等扩展字段。

需求判定 + 隐性需求挖掘规则

✅ 新需求 New

系统不存在对应业务资产，全新业务模块、全新页面、全新业务流程；无基线可对比。
动作：新建测试需求资产 V1，从零拆解显性+隐性测试点。

📈 增量需求 Increment

已有业务基线，在原有流程上叠加新功能；原有逻辑保持不变。
动作：基线Vn升级Vn+1；原有需求基线保留，新增显性+隐性测试点，原有用例保留。

✏️ 修改需求 Modify

已有功能逻辑变更、页面UI变更、接口参数变更，原有业务主体不变。
动作：基线Vn升级Vn+1；基线比对，标记原有需求【修改】，关联显性、隐性测试点同步更新。

🔧 缺陷修复 BugFix

线上/测试缺陷修复，业务规则不变，修复bug。
动作：基线Vn升级Vn+1；仅更新缺陷关联测试点与回归用例，补充隐性回归场景。

🚀 需求增强 Enhance

原有业务逻辑不变，补充边界场景、优化交互，不改动主流程。
动作：基线Vn升级Vn+1；补充增强类显性+隐性测试点，原有主流程用例保留。

🗑️ 废弃/删除需求 Deprecated

功能下线，业务流程不再使用。
动作：基线Vn升级Vn+1，资产标记废弃；关联用例标记归档，历史基线保留只读。

隐性需求挖掘规则（Agent内置）

  • 账号登录场景：账号密码错误、密码过期、租户切换、域账号校验、二次验证码、会话过期重登
  • 动态页面场景：点击后弹窗渲染、级联下拉、表格懒加载、tab切换、折叠面板、异步加载内容
  • 权限场景：角色、数据隔离、越权访问（Story经常不描述）
  • 异常场景：网络超时、表单非法输入、空值、超长文本、重复提交
  • 数据一致性：保存/提交后数据落库校验、列表刷新、状态流转
  • 业务约束：唯一性、数值范围、状态前置依赖、业务闭环校验
  • UI隐性规则：必填星标、按钮灰化、弹窗阻断、提示文案

✅ 标准化交付产出（不再只依赖JSON）

  • Markdown需求拆解文档：Epic/Story信息、显性需求、隐性需求、业务前置约束、业务流程图、测试点清单（评审主文档）
  • Excel手工用例：case name、step、expected result、关联Story、测试点ID、优先级、用例类型
  • Cucumber Feature：标准化Gherkin场景，接入pw_automation_framework执行
  • 资产JSON仅作为元数据索引文件，用于程序读取，不对外作为交付文档

版本迭代规则：New：V1；其余全部Vn+1；每次变更生成新版本，旧资产不可原地覆盖，用于基线比对。资产生命周期：草稿→评审通过→归档→废弃。

测试点基线比对结果分类

  • 新增测试点：新业务逻辑，包含显性+挖掘出的隐性场景，新增手工case + 新增Cucumber自动化case
  • 修改测试点：原有业务规则变更，更新手工case，更新自动化脚本；同步校验关联隐性场景是否同步变更
  • 增强测试点：原有逻辑不变，补充边界/异常隐性场景，自动化case增强
  • 删除测试点：业务下线，对应手工、自动化用例标记删除，归档保留历史版本
  • 保留测试点：不受本次需求变更影响，原有用例不变，回归验证；同时校验关联隐性场景是否依然有效

Cucumber Feature 示例（适配 pw_automation_framework，绑定Story）

# Jira: Epic XXX-1001 | Story XXX-2005
Feature: 多任务Agent页面元素拾取与测试流程执行
  As a 自动化测试工程师
  I want to use RoleElementPicker 拾取页面无障碍树元素
  So that 自动生成Playwright脚本并执行业务流程

  Background:
    Given 初始化pw_automation_framework测试环境
    And 使用账号凭证池完成系统登录（支持账号密码/SSO）

  Scenario: 交互触发动态弹窗，抓取页面无障碍树并生成元素定位器
    Given 导航至目标业务页面
    When 点击查询按钮，触发动态弹窗渲染
    And 通过Playwright MCP获取当前页面无障碍树快照
    Then RoleElementPicker输出稳定role+name元素定位器

Playwright MCP页面探测链路（支持动态渲染页面）

  1. PageDiscoveryTask接收credentialKey，从账号凭证池读取整套登录信息：用户名、密码、扩展字段（租户ID、域账号等），支持账号密码登录或SSO单点登录两种模式
  2. 初始化Playwright浏览器，读取凭证执行页面登录，完成后导航目标业务页面
  3. 动态交互循环探测：自动执行交互动作（点击Tab、下拉选择、输入、展开折叠面板），触发弹窗、表格、级联选项等异步动态组件渲染；每一步交互完成后，调用MCP拉取无障碍树快照，多轮收集全部状态的页面元素
  4. RoleElementPicker解析多组无障碍树快照集合，基于role+name生成稳定元素定位器，规避脆弱xpath/css选择器，同时记录触发动态组件所需交互步骤
  5. 框架内部编排TestFlow动作序列与断言规则，包含触发动态渲染的前置交互步骤，生成Cucumber Feature文件与Playwright Java Step代码，自动写入Jira Story元信息
  6. 将TestFlow、多状态元素清单、feature、java step写入版本化测试资产库，生成资产新版本Vn；同步输出Markdown需求拆解文档+Excel用例
  7. 任务完成后输出探测报告，所有资产文件仅本地生成，不自动提交或上传任何文件
🔒 安全说明： 账号、密码、租户等敏感凭证统一由环境变量注入，不会明文打印到控制台/日志；日志自动掩码脱敏，避免账号密码泄露。账号凭证池独立存储，资产元文件不保存任何明文账号密码。
